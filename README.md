# JDC - Jovi 2026

Uma aplicação Terminal User Interface (TUI) desenvolvida com Textual para navegação interativa de questões de programação.

## Características

- Interface de usuário moderna baseada em terminal
- Navegação entre múltiplas telas
- Sistema modularizado de questões
- Estrutura escalável para novos conteúdos

## Requisitos

- Python 3.10+
